# EnviroVitals

EnviroVitals is a ZIP-level One Health web app for cardiovascular-kidney-metabolic (CKM) health. For any US ZIP it shows live conditions (hourly EPA AirNow AQI, active NWS alerts, Open-Meteo feels-like temperature), the nearest EPA annual PM₂.₅ monitor, public drinking-water-system records with UCMR 5 sample maximums compared against EPA limits, and CDC community CKM prevalence ranked against all US ZCTAs. It turns those values into a deterministic checklist whose wording depends on the actual numbers and on the CKM conditions a user optionally selects (high blood pressure, diabetes or prediabetes, kidney disease, heart disease or stroke, excess weight, age 65+). Checking actions complete raises the **EnviroHealth action-progress score**; the score is not a personal health or exposure-risk estimate. Any missing input is shown in gray and never treated as zero, clean or a non-detection.

## Run the web app

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. The landing page opens a nationwide county map. Select a county to see its average index and open an example ZIP, or use **Explore a ZIP** to open the profile panel (initially ZIP `10013`). Pan or zoom to explore, including Alaska and Hawaii; the ZIP report scrolls as a single panel on phones.

The interface uses Next.js App Router, React, and TypeScript. Profile data is served by `/api/profile?zip=10013`; live conditions by `/api/live?lat=40.72&lon=-74.00` (cached 10 minutes, refreshed by the panel every 10 minutes). No account or API key is required: AirNow file products, the NWS alerts API and Open-Meteo are all keyless. Checklist progress, the water-source choice and the optional CKM condition selections are stored in browser local storage.

## Data coverage and methods

- **Live conditions:** `/api/live` parses EPA AirNow’s public `reportingarea.dat` file (hourly observations, Air Quality Action Day flags and next-day forecasts for ~750 reporting areas) and uses the nearest reporting area within 60 miles; the file is held in memory per server instance for 10 minutes. NWS active alerts are fetched for the point with a `User-Agent` header as the API requires. Open-Meteo supplies the feels-like (apparent) temperature, today’s and tomorrow’s range and humidity; its CAMS air-quality model is used only when no AirNow reporting area is in range and is labeled a model estimate. Each source fails independently to `null`, which the UI shows in gray.
- **CKM prevalence:** CDC PLACES 2025 provides 2023 BRFSS estimates for populated 2020 Census ZIP Code Tabulation Areas (ZCTAs). The snapshot covers 32,520 ZCTAs with at least 50 adults. It includes coronary heart disease, stroke, high blood pressure, high cholesterol, diabetes, and obesity. The newest ZIP-level chronic kidney disease measure available is PLACES 2023, based on 2021 BRFSS data. CDC discontinued the CKD measure in later releases; older CKD ZCTA IDs are joined to current records by five-digit ZCTA code. The profile route also returns a midrank national percentile for each measure (`healthRank`) and the national median (`healthMedian`), so the UI can say "higher than 82% of US ZCTAs".
- **Outdoor air:** EPA AirData 2025 annual concentration records. Each profile uses the nearest complete PM₂.₅ monitor within 50 miles of the Census ZCTA centroid when available, otherwise the postal ZIP coordinates returned by the ZIP place lookup. The app displays monitor distance. This is a measured monitor value, not an address-level estimate or current AQI. EPA’s annual 9.0 µg/m³ standard is a three-year average; EnviroVitals uses it only as a screening reference for the single 2025 monitor value, not to determine attainment.
- **Map:** County polygons from the 2024 Census cartographic boundary file are colored by the arithmetic mean of available ZIP index values whose postal coordinates fall inside each county. Counties without a matching index are gray. The red-to-blue palette follows the supplied Opportunity Atlas reference image, with higher index values in red. The underlying snapshot has 40,977 unique GeoNames ZIP points across all 50 states and DC; 40,865 with an index matched a county boundary. Each ZIP index combines matching CDC ZCTA health estimates and state air context, using state health fallback per missing measure. OpenStreetMap public raster tiles load directly from `tile.openstreetmap.org` without an API key. The basemap is visually muted to keep the county colors prominent; street labels are part of the raster tiles. Attribution credits OpenStreetMap contributors and the U.S. Census Bureau. Tile requests follow the [OSM tile usage policy](https://operations.osmfoundation.org/policies/tiles/) with browser caching and a valid referrer, without bulk downloads or offline prefetching. ZIP indices use equal weights for the air and CKM components; CKM averages cardiac, kidney, and metabolic percentile ranks. Health inputs use national ZCTA percentile references; state health fallbacks use adult-population-weighted aggregates of matched CDC ZCTAs; air inputs are means of complete EPA sites. Incomplete components are omitted and remaining weights renormalized (Idaho, Florida, Pennsylvania). These are exploratory ZIP and state estimates, not ZIP measurements, a validated clinical risk score, or the household checklist score. Full calculation and coverage are described at `/about#national-map`.
- **Drinking water:** EPA’s current public-water-system service-area map is queried at the same ZIP-area coordinates. The app shows the system name, boundary source/model label, and population served when available. It joins EPA’s final UCMR 5 analytical records (2023–2025) by PWS ID and summarizes treated-water entry-point and distribution-system samples. These are system samples, not tap tests. A system absent from UCMR 5 may not have been selected for monitoring; absence is not a non-detection.
- **Task rules:** Steps are grouped as Right now, Air at home, Drinking water, CKM care and One Health. Right-now steps follow EPA’s AQI categories (with stronger wording for selected sensitive conditions), the NWS heat-index bands applied to the feels-like temperature (80/90/103/125°F), a 32°F cold threshold, and active NWS alerts (heat, air quality, cold, and other severe or extreme events). Air tasks change when the nearest annual PM₂.₅ reading is above 9.0 µg/m³. Water tasks compare UCMR 5 sample maximums with the 2024 PFAS limits (PFOA/PFOS 4.0 ng/L; PFHxS, PFNA and HFPO-DA 10 ng/L, labeled as proposed for rescission since May 18, 2026) and EPA’s 10 µg/L lithium reference level (flagged above 15 µg/L, matching EPA’s one-significant-digit rounding), and depend on whether the user selects public water, private well, or unsure. CKM-care steps use the selected conditions and the ZIP’s national percentile ranks; One Health steps extend air, heat and water precautions to pets and add medicine take-back, Burn Wise, source-water and algal-bloom steps. Full rules are listed at `/about#action-rules`.
- **Score:** Completed task points divided by all points in the current checklist, rounded to a whole number. Task rules and points are fixed; completion only changes the progress score. A ZIP or source-mode change loads that profile’s separate saved checklist; condition selections apply to every ZIP.
- **CKM stage context:** Selected conditions map to an AHA CKM stage context (heart disease or stroke → Stage 4; hypertension, diabetes or CKD → Stage 2; excess weight → Stage 1; none → Stage 0–1) that orders the guidance. It is not a diagnosis; Stage 3 can only be established by testing.

Sources are linked in the app under **Sources & methods**. Valid postal ZIPs recognized by the ZIP place lookup can receive air and water results. CKM estimates are available only for matching populated Census ZCTAs in CDC PLACES; a missing estimate is shown as unavailable, never as zero. The data layers use different source years and geographic methods. ZCTAs approximate, but are not identical to, USPS ZIP delivery areas.

## Refresh public data snapshots

```bash
npm run data:refresh
npm run data:map
python3 scripts/build_county_map.py
```

This downloads CDC PLACES 2025 and 2023 ZCTA data, EPA AirData 2025 annual monitor data, and the final EPA UCMR 5 archive. It writes compact JSON snapshots under `src/data/`. `data:map` then downloads GeoNames US postal coordinates and builds `public/data/national-map.json` from the current CDC/EPA snapshots. `build_county_map.py` downloads 2024 Census county boundaries and builds `public/data/county-map.json` from those ZIP indices. To reuse downloaded geography files, pass `--postal-file /path/to/US.txt` to `build_national_map.py` or `--county-zip /path/to/cb_2024_us_county_5m.zip` to `build_county_map.py`. The map JSON is fetched separately in the browser; do not statically import large data snapshots into TypeScript (literal inference can exceed the compiler’s Map size limit). The EPA water-system boundary layer is queried live. Python 3 and network access are required for fresh downloads; the scripts use only the Python standard library.

## Use notice

EnviroVitals provides community context and general public-health information only. It does not provide a diagnosis, treatment recommendation, or assurance of a home’s air or drinking-water quality, and the optional condition selections only order general guidance. Consult a qualified clinician for health and medicine questions, your water provider or a state-certified lab for water testing, and EPA/AirNow and NWS for current advisories.
